# 音乐播放器 (MusicPlayer)

Android music player built with Kotlin + Jetpack Compose + Material 3.

## Features

- Local music playback via MediaStore
- Playlists and favorites with Room
- LRC lyrics display with synchronized scrolling
- Background playback with MediaSessionService
- Material You dynamic theming
- Mini player bar + full screen player with rotating album art

## Tech Stack

- Kotlin + Jetpack Compose + Material 3
- AndroidX Media3 (ExoPlayer)
- Room Database
- Hilt Dependency Injection
- Coroutines + Flow
- Min SDK 26, Target SDK 34
